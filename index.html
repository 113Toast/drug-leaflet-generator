Gemini API 申請與使用教學

  1. 前往 Google AI Studio（網址：aistudio.google.com）並登入你的 Google 帳號。
  2. 點擊左側選單的 「Get API key」 → 「建立 API key」（可選現有專案或新建專案）。
  3. 複製產生的金鑰（通常以 AIza 開頭），貼到下方「Gemini API Key」欄位即可。
  4. 金鑰只會保存在你這台瀏覽器的本機（localStorage），不會上傳到 GitHub；若沒填金鑰，「一鍵精簡重點」仍可免金鑰執行本機條列精簡。
