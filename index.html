📖 高齡多重用藥檢核與衛教系統 — 使用說明

一、臨床操作 4 步驟

  1. 輸入病人資訊：填入年齡、性別、eGFR 與 CrCl，並勾選相關共病／症候群（心衰竭、跌倒史、失智等）。
  2. 加入多重用藥：可用「10 碼健保碼、商品名、學名」連續搜尋加入，或切換至「📷 處方箋拍照辨識」一次匯入整張處方箋。
  3. 藥師檢視 2023 Beers Criteria 警示：左側即時顯示潛在不適當用藥（Table 2～7），包含多重抗膽鹼負擔、≥3 種中樞神經作用藥併用、腎功能劑量切點。警示預設僅供藥師評估，若需印出給長輩可勾選「附上白話回診討論提醒」。
  4. 勾選列印欄位並匯出 PDF：勾選要印出的藥品與欄位（外觀、作用、副作用、生活與飲食建議），系統以雙欄大字卡片排版並監測頁數不超過 2 頁 A4。

二、關於 2023 AGS Beers Criteria 提醒

  • Beers Criteria 標示的是「潛在不適當用藥（PIM）」，並非絕對禁忌，應結合長輩治療目標與醫師共同討論，切勿讓病人自行突然停藥。
  • 本系統內建高齡白話衛教字典與生活飲食模板，免 API 即可使用；填入 Gemini API Key 後可啟用「處方箋拍照辨識」與「AI 一鍵白話改寫」。
