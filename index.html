Gemini API 申請與使用教學

  1. 前往 Google AI Studio（aistudio.google.com）登入 Google 帳號。
  2. 點擊左側 「Get API key」→「建立 API key」，複製 AIza 開頭的金鑰。
  3. 貼到下方「Gemini API Key」欄位；遇到 503 高流量時會自動重試，所有輸出皆自動轉為繁體中文。

📖 用藥衛教單張生成系統 — 使用說明

一、快速開始（3 步驟完成單張）

  1. 搜尋並帶入藥品：在「🔍 搜尋藥品」輸入中文品名、英文名、學名或許可證字號，點選清單項目即自動帶入衛福部食藥署（TFDA）官方仿單重點與藥品外觀圖。
  2. 編輯與條列精簡：系統帶入後會自動轉為繁體條列；如需進一步濃縮可按「✂️ 一鍵精簡重點（條列式）」，或直接在下方各欄位手動增修（每換一行即自動成為一個項目符號）。
  3. 預覽與匯出 PDF：確認右側 A4 預覽無誤（手機版請點頂部「📄 A4 單張預覽」），點擊右上角「🖨️ 列印 / 匯出 PDF」，於列印視窗選擇「另存為 PDF」或直接印出。

二、進階排版與實用功能

  • 核對官方原件：選取藥品後，可點「🌐 官方電子仿單網頁」或「📄 官方仿單 PDF」直接開啟食藥署頁面核對完整內容。
  • 特殊劑型獨立區塊：陰道乳膏、直腸液劑、吸入劑等特殊劑型會自動拆出「給藥與清潔方式」；如需附步驟圖片，可勾選「4. 圖文操作步驟」自行上傳圖檔。
  • 副作用分級標示：系統自動區分「立即停藥並盡速就醫（紅字警示）」與「一般觀察」兩類，亦可手動勾選「緊急就醫標示」或增刪項目。
  • 進階 AI 輔助（選用）：本系統預設免 API 即可完整使用；若需使用「處方箋照片辨識」或「AI 語意重組」，請至「⚙️ 系統設定」勾選啟用並填入個人 Gemini API Key。
⚠️ 臨床核對與隱私提醒：
• 系統資料源自 TFDA 公開仿單，部分藥品原仿單未單獨列出所有段落（標題旁將標示「原仿單未獨立列出」），交付病人前請務必由藥師或醫療人員再次核對劑量與醫囑。
• 本系統為純前端網頁，所有編輯內容與選填之 API Key 僅保存於您本機瀏覽器中，不會上傳至任何第三方伺服器。
